# AI 生成概念图资产说明

本目录用于存放 FinDSL Forge 项目的 AI 生成视觉资产。图片用于项目介绍、答辩材料、封面页、技术路线说明和交付包视觉补充，不作为真实运行截图、测试证据或 Doris 性能证据。

## 生成方式

- 底图生成：使用 Codex 内置 `imagegen` 能力生成。
- 提示词参考：参考 `external_references/image_generation/GPT-Image2-Skill` 中的 GPT-Image2-Skill 提示词组织方式，按照“用途、主体、构图、风格、约束、避免项”拆解提示词。
- 中文文字：最终交付图中的主要中文标题、说明、用途文字均由本地脚本使用 Windows 中文字体二次叠加，避免 AI 直接生成中文造成错字、缺字或笔画异常。
- 证据边界：图片中的“AI 生成底图”不能替代项目真实截图。真实测试、Git、Doris、运行日志和交付包证据仍以 `outputs/截图证据包*`、`results`、`reports`、`submission_artifacts` 等目录中的实际文件为准。

## 使用建议

1. 在答辩 PPT 中使用 `final_chinese/` 目录下的图片，不直接使用 `raw_selected/` 中的原始图。
2. 若评委要求“真实运行证据”，应切换到截图证据包中的终端、测试、Doris、Git 和文件列表截图。
3. 若用于论文或技术报告，建议在图注中写明“概念示意图”，不要把它描述成实验结果图。
4. 若后续继续生成图片，应继续采用“AI 生成底图 + 本地叠加中文”的方式，保证中文内容可检查、可修改、可复现。
