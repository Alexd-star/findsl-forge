# Phase 27：事件时序投影与跨日期候选集

## 1. 阶段目标

Phase 26 后，旧严格成功集只剩四条由事件组合语义造成的可落地缺口：同一布尔合取中的今日/昨日事件、金叉事件按月或按连续交易日量化，以及滚动极值事件与无日期当前标量的组合。旧计划器要么要求所有事件共享日期，要么先筛选事件真值再执行 `CONS/EXIST`，后者会丢掉不匹配行，使连续段和“每月存在”的统计失真。

本阶段不增加样例专用分支，而是补充两个关系合同：跨日期事件先各自形成证券候选集，再做集合运算；时序事件先投影逐行事件布尔值，再交给已有的类型化时序算子。无日期普通标量统一采用最新交易日快照，避免与周期事件连接时扫描全历史。

## 2. 跨日期事件分解

规划器按规范化日期合同为事件项分组。空日期和“今日”都归入 `latest_session`；昨日、固定日期、交易日集合和周期范围保留各自的稳定合同 ID。不同日期组不能压入一个行级 `WHERE`，而是分别生成带 `(mktcode,tgtcode)` 稳定键的候选关系：`and` 使用 `INTERSECT`，`or` 使用 `UNION`，否定事件继续使用具有三值逻辑边界的 `EXCEPT`。

这种分解使“今日历史新低，并且昨日历史新高且非 ST”保持两个日期快照，而不是把今日和昨日谓词错误施加到同一行。最终候选键连接基础行情最新快照，输出日期口径保持确定。

## 3. 时序事件投影

新增 `PhysicalEventProjection`。该算子在完整证券时间序列上用 `LAG` 计算上穿、下穿或金叉，并将结果写入显式事件列。日期裁剪发生在事件投影之后，因此窗口首行仍能读取范围外前一交易日，避免把周期首日的真实穿越漏掉。

投影结果进入原有 `PhysicalTemporal`：`EXIST` 聚合匹配次数；“每月”先按自然月分桶并对事件列取 `MAX`；连续 N 日使用 `all_seq-matched_seq` 的 gaps-and-islands 方法计算最长连续段。窗口函数只出现在派生关系投影，不进入 Doris `WHERE`。

## 4. 极值短写与当前快照

官方 `80内` 被规范化为 80 个交易会话，Doris 行框为 `ROWS BETWEEN 79 PRECEDING AND CURRENT ROW`。直接无日期指标在非时序计划中获得最新数据日分区谓词，该谓词下推到稳定行情扫描；显式日期、聚合、排名和时序计划不受影响。

真实 Doris 试跑还暴露了单日极值窗口的方言边界：`0 PRECEDING` 虽可由 SQLGlot 解析，但 Doris 拒绝。后端现将一日窗口渲染为 `ROWS BETWEEN CURRENT ROW AND CURRENT ROW`，并加入回归测试与实际执行证据。

## 5. 官方漏斗与假阳性审计

Phase 26 基线为 `686/1097`。Phase 27 达到 `690/1097（62.90%）`，新后端总成功数为 713。新增成功恰好为 Excel 行 359、3762、3763、5008，历史成功零回退。

四条新增成功逐条验证后端安全校验、无占位谓词、候选集合合同或事件投影合同、真实 `LAG`、月桶或连续岛结构，结果为 `4/4 PASS`。剩余 407 条旧严格成功集缺口全部归入缺失范围成员、缺失领域数据/能力、空行业成员字段、T+0 等不可由当前三张官方日频表证明的类别。

## 6. 真实 Doris 证据

`scripts/collect_phase27_event_semantics_evidence.py` 使用四组独立参考 SQL：有界周期内金叉存在、当前月每月金叉、今日/昨日一日极值候选交集、80 会话新高与最新收盘价组合。每组保存完整结果集 SHA-256、差异样本、两轮耗时、结构合同和 EXPLAIN 摘要。

在 13,650,347 行官方基础行情和等行数技术特征表上，四组结果均非空，生成 SQL 与独立参考 SQL 完整行集哈希一致 `4/4`，结构合同 `4/4 PASS`。最高两轮 P95 约 2.1 秒，低于赛题 10 秒目标。

## 7. 当前边界

本阶段完成的是当前官方数据可证明的事件组合能力，不改变缺失数据域边界。概念、指数、自定义板块、财务、基金、账户画像、分钟行情、行业成员和不可由日频三表确定的状态仍返回结构化诊断，不生成假表、假字段或占位 SQL。
