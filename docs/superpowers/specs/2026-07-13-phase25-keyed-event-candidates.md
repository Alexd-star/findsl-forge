# Phase 25：证券键事件候选关系

## 1. 阶段目标

行情事件通常发生在历史交易日，而最终选股结果需要输出当前证券快照。此前事件计划直接输出 `(mktcode,tgtcode,bizdate)`，因此无法与聚合、指定证券标量或不同日期作用域的条件安全组合：按三列做 `INTERSECT` 会因日期不同漏掉证券，只按行拼接又会放大结果或混淆事件量词。

Phase 25 引入证券键候选关系。每个分支先独立完成自己的日期、窗口、聚合和范围语义，再按 `(mktcode,tgtcode)` 做集合运算，最后统一回连官方基础行情的最新交易日。该设计对应关系数据库中的半连接候选集，而不是把布尔事件退化成普通标量。

## 2. Physical IR 合同

新增 `PhysicalCandidateSetOperation`，显式携带：

- `left`、`right`：两个已验证物理计划；
- `operation`：`intersect`、`union` 或 `except`；
- `anchor_resource_id`：最终输出快照的受控资源；
- `key_semantics=security`：集合运算只比较证券稳定键；
- `output_date_policy=latest_anchor`：输出日期由锚点资源最新分区确定。

验证器要求锚点资源具备分区键，并递归验证两个分支。后端把每个分支投影为去重证券键，再使用 SQLGlot 构建 `INTERSECT/UNION/EXCEPT` AST；集合结果与最新基础行情按双键连接，最终仍输出标准三列。

## 3. 混合谓词分解

规划器只在现有事件行计划无法正确承载时启用候选关系：

1. 事件与聚合函数共同出现；
2. 事件与 `queryData` 指定证券标量共同出现；
3. 事件和普通指标使用不同日期作用域；
4. 事件与周期末标量、增长率或其他命名关系组合。

同一日期下的事件与直接指标仍保留原有单关系快速路径，避免无谓增加扫描和集合节点。顶层 `and` 被映射为证券键交集，顶层 `or` 被映射为证券键并集；括号内部的事件析取仍在事件关系中按逐日布尔表达式计算。

## 4. 事件量词和三值逻辑

带时间窗口的 `event=True` 表示窗口内至少存在一个可判定交易日发生事件。`event=False` 不能解释为“存在一天没有发生”，否则几乎所有证券都会误选；本阶段将其定义为：

```text
窗口内事件可判定的证券集合 EXCEPT 窗口内至少发生一次事件的证券集合
```

“可判定”要求事件表达式结果为 `True` 或 `False`。技术指标缺失、窗口首行没有前值或其他 SQL `NULL` 不进入候选全集，因此不会被错误当作未发生。没有填写 `date` 的事件默认在官方数据最新交易日判定，但 `LAG`、滚动极值和位置窗口仍读取必要历史行，再在外层应用结果日期约束。

实现层不会为上述集合差重复扫描两次完整历史窗口。`PhysicalEventFilter` 使用 `quantifier=none` 携带事件真值谓词、可判定谓词和锚点合同；Doris 后端在一次事件窗口结果上按证券分组，以两个 `MAX(CASE WHEN ...)` 分别证明“存在可判定记录”和“不存在真事件”。这种 `HAVING` 反存在计划与逻辑 `EXCEPT` 等价，但避免重复计算 13,650,347 行窗口。

## 5. 位置算法修复

代码复核发现 `position()` 的归一化位置原意为 `(value-min)/(max-min)`，但分子未显式生成括号时，Doris SQL 运算优先级可能解释为 `value-min/(max-min)`。本阶段在 SQLGlot AST 中加入 `Paren(Sub(...))`，并新增回归断言。五档边界继续保持：当前值等于最小/最大时优先返回“最低/最高”，其余值按 0.25 和 0.75 阈值划分低、中、高。

## 6. 官方工作簿结果

Phase 24 基线为 `667/1097`。Phase 25 临时漏斗达到 `675/1097（61.53%）`，新后端总成功数为 695。八条旧严格成功问句由失败转为成功，其中六条原为事件组合缺口，两条原为事件与指标日期作用域不一致。原 `PHYSICAL_EVENT_COMPOSITION_UNSUPPORTED` 迁移缺口归零，事件日期作用域迁移缺口由四条降为一条。

## 7. 真实 Doris 证据

`scripts/collect_phase25_event_candidate_evidence.py` 在 13,650,347 行官方基础行情上验证五类非空场景：周期新高与分组平均、窗口内事件从未发生、最新位置与指定证券标量、事件析取与多增长率关系、事件和指标不同日期作用域。

预采集结果为 `5/5` 完整结果集 SHA-256 一致且全部非空。参考 SQL 独立实现事件窗口、证券键交并差、三值可判定全集、聚合关系和最新快照回连，不读取编译器 Physical IR 或 SQL AST。事件否定由重复窗口集合差优化为单扫描反存在计划后，两轮采集的最大 P95 约 2.44 秒，低于赛题逐问句 10 秒目标。

## 8. 当前边界

复杂事件槽位中的非空聚合或时序计数仍需专门合同，不能忽略。不同事件本身使用互不兼容日期作用域时，只有能被布尔集合代数无损分解的形式才应接受。缺失行业、概念、指数和自定义板块成员数据继续返回结构化诊断，不允许用候选集合伪造数据域。
