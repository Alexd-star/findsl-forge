# 09 接口文档

本文档说明 CLI 和 Web Demo API。当前项目没有独立后端框架，接口由 `src/findsl/cli.py` 和 `src/findsl/demo.py` 提供。

## 1. CLI 总入口

```powershell
python -m findsl.cli <command> [args]
```

常用命令：

| 命令 | 作用 | 示例 |
|---|---|---|
| `official-slot-parse` | 用 ANTLR 解析官方 DSL。 | `python -m findsl.cli official-slot-parse "indicator('', '', '涨幅', '今日', '', '', '') > 5%" --mode strict --frontend antlr --json` |
| `official-slot-ir` | 构建正式 Typed AST/Logical IR。 | `python -m findsl.cli official-slot-ir "indicator('', '', '成交量', '今日', '', '', '') > 100" --json` |
| `official-slot-physical` | 构建正式 Physical IR。 | `python -m findsl.cli official-slot-physical "indicator('', '', '成交量', '今日', '', '', '') > 100" --json` |
| `official-slot-backend` | 生成经校验的 SQLGlot Doris SQL。 | `python -m findsl.cli official-slot-backend "indicator('', '', '成交量', '今日', '', '', '') > 100" --json` |
| `compile` | 编译内部 FinDSL；仅作兼容样例。 | `python -m findsl.cli compile 'filter(indicator("close") > 10)'` |
| `diagnose` | 诊断非法 DSL。 | `python -m findsl.cli diagnose 'filter(indicator("clos") > 10)' --json` |
| `verify-sql` | SQL/reference 等价验证。 | `python -m findsl.cli verify-sql 'filter(SUM(indicator("volume"), 3) > 300)' --data-dir data/samples` |
| `suggest-dsl` | 中文需求转 DSL 候选。 | `python -m findsl.cli suggest-dsl 'A股每日换手率前50%' --json` |
| `validate-llm-candidates` | 验证 LLM 返回候选。 | `python -m findsl.cli validate-llm-candidates --response-file data/samples/llm_candidate_response.json --json` |
| `llm-suggest-dsl` | 调用 OpenAI-compatible provider。 | `python -m findsl.cli llm-suggest-dsl '近3日成交量累计大于300' --model '<model>' --json` |
| `official-suite` | 运行官方风格套件。 | `python -m findsl.cli official-suite --json` |
| `readiness-report` | 生成提交前报告。 | `python -m findsl.cli readiness-report --output reports/submission_readiness.md` |
| `serve-demo` | 启动 Web Demo。 | `python -m findsl.cli serve-demo --host 127.0.0.1 --port 8765` |

## 2. Web API

启动：

```powershell
python -m findsl.cli serve-demo --host 127.0.0.1 --port 8765
```

### `GET /api/examples`

返回 Demo 可用样例，包括官方正例、负例、真实行情样例和基础用例。输出用于页面下拉选择和演示。

### `POST /api/suggest`

输入中文文本，返回 DSL 候选及验证情况。请求体根据当前实现推断类似：

```json
{
  "text": "A股每日换手率前50%",
  "dataset": "sample"
}
```

输出包含候选 DSL、规则名称、置信度、是否通过验证等字段。

### `POST /api/analyze`

输入内部 FinDSL 或选定候选，返回 compile、AST、SQL、explain、verification、diagnostics 和 evidence 摘要。该接口属于保留的内部样例链路。

### `GET /api/official/examples`

返回官方七槽位 DSL 的正例、预期拒绝例和典型能力边界，用于比赛编译工作台。

### `POST /api/official/analyze`

调用正式 `compile_official` 管道，返回 ANTLR frontend、Typed AST、Logical IR、Physical IR、SQLGlot Doris SQL、候选选择、阶段 trace 和结构化诊断。该接口不应静默回退旧编译器；失败时保留已完成阶段的 partial evidence。

## 3. Provider 接口

`llm_provider.py` 面向 OpenAI-compatible `/chat/completions` 接口。系统会请求 JSON 风格 DSL 候选，但 provider 输出仍然必须通过 `validate_llm_candidates`。需要的环境变量包括：

```powershell
$env:FINDSL_LLM_API_KEY="<your key>"
$env:FINDSL_LLM_MODEL="<provider-model>"
$env:FINDSL_LLM_BASE_URL="https://api.openai.com/v1"
```

## 4. 接口安全边界

所有接口都不应执行任意 SQL。即使用户或 LLM 返回 SQL 文本，系统也会拒绝直接 SQL 候选，只允许受控 DSL 进入编译链路。当前 Demo 适合本地答辩，不具备完整生产鉴权、限流和多租户隔离；生产部署前必须补齐这些治理。
