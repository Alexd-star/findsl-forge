# 03 操作手册

本文档说明项目从代码检查、启动 Demo、运行测试、生成报告到导出提交包的操作流程。命令默认在项目根目录执行。

## 1. 环境准备

推荐使用 Python 3.9 及以上版本。当前项目核心包没有强制运行时第三方依赖；开发、测试和 reference oracle 需要 `pandas` 和 `pytest`。

```powershell
python --version
$env:PYTHONPATH="src"
python -m pytest --version
```

如果当前 shell 找不到刚安装的工具，可参考本机全局说明刷新 PATH。

## 2. 常用 CLI 操作

编译 DSL：

```powershell
python -m findsl.cli compile 'filter(indicator("close") > 10)'
```

验证 SQL 与 reference 结果：

```powershell
python -m findsl.cli verify-sql 'filter(SUM(indicator("volume"), 3) > 300)' --data-dir data/samples --json
```

运行官方风格套件：

```powershell
python -m findsl.cli official-suite --json
```

生成 readiness 报告：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\submission_readiness.ps1
```

## 3. Web Demo 操作

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\serve_demo.ps1
```

浏览器访问 `http://127.0.0.1:8765`。如果端口被占用，可以通过 CLI 直接启动并指定端口：

```powershell
python -m findsl.cli serve-demo --host 127.0.0.1 --port 8766
```

## 4. Doris 资产操作

生成 Doris SQL 资产：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\generate_doris_assets.ps1
```

资产位于 `deploy/doris/`，按 `01_schema.sql`、`02_sample_data.sql`、`03_build_prefix_tables.sql`、`04_smoke_queries.sql` 顺序执行。

## 5. 采集 Doris 证据

在 Doris 运行并加载数据后执行：

```powershell
$env:DORIS_HOST="127.0.0.1"
$env:DORIS_PORT="9030"
$env:DORIS_USER="root"
powershell -ExecutionPolicy Bypass -File .\scripts\collect_doris_evidence.ps1
```

如果使用 Docker 拉取镜像并需要代理，可使用：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\prepare_doris_scale_evidence.ps1 -ProxyUrl "http://127.0.0.1:7897"
```

## 6. 提交包导出

readiness 通过后，导出可提交证据快照：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\export_submission_artifacts.ps1
```

导出的轻量证据位于 `submission_artifacts/evidence_snapshots/`。

## 7. 操作失败时的处理

- Python 找不到 `findsl`：确认 `$env:PYTHONPATH="src"`。
- `pytest` 缺失：安装开发依赖或使用已有 Python 环境。
- Doris 连接失败：确认 Docker Desktop、Doris 容器、9030 端口和 MySQL 客户端。
- readiness 出现 Git dirty warning：先确认是源码变化、报告变化还是证据快照变化，再决定提交或还原。
