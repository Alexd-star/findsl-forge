# 01 项目简介

FinDSL Forge 是一个面向金融选股场景的 DSL 编译与 Apache Doris SQL 加速系统。项目服务于中国研究生金融科技创新大赛赛题 19，核心任务是把可审计、可验证的选股表达式编译成高性能 Doris SQL，而不是让大模型直接生成不可控 SQL。

## 项目定位

本项目定位为“金融选股 DSL 编译器 + Doris 执行证据 + AI 辅助入口”的工程化产品。正式官方链路依次经过 ANTLR4 解析、Typed AST、领域绑定、Logical IR、等价规则、Physical IR、SQLGlot Doris AST、安全验证和独立结果核验。用户也可以输入中文自然语言请求，但系统只让模型产生 DSL 候选；核心正确性仍由确定性编译器和独立 oracle 负责。

## 解决的问题

金融筛选条件通常包含连续性、存在性、均线、滚动和、横截面排名、日期区间和多表指标。例如“连续 3 天主力净流入为正后按换手率排名”“近 120 日成交量累计大于阈值”“日期区间内收盘价高于均线”。这些条件如果直接手写 SQL，容易出现窗口范围、NULL 语义、排序口径和表 join 口径错误；如果直接交给 LLM，更难保证可审计和可复现。

FinDSL Forge 把复杂表达先收敛为受控 DSL，再由编译器生成 Doris SQL。系统还提供 Pandas reference oracle 和 SQLite 本地执行器，用于在进入 Doris 前验证 SQL 结果是否符合 DSL 语义。

## 核心能力

- DSL 编译：支持 `filter`、`then`、`rank`、`date_between`、`CONS`、`EXIST`、`MA`、`SUM`、`MAX`、`MIN`、`RET`。
- 语义校验：拦截未知指标、非法窗口、非法 rank 参数、裸字段绕过、除零等问题。
- Doris SQL：生成窗口函数、CTE、日期下推、prefix-sum 优化 SQL。
- 正确性验证：使用 Pandas reference 和 SQLite SQL 执行结果做等价比较。
- 性能证据：支持 Doris EXPLAIN、行数一致性、baseline/optimized latency 和 10x speedup marker。
- AI 辅助：中文 NL2DSL 模板、LLM 候选安全验证、OpenAI-compatible provider 入口。
- 工程交付：Web Demo、提交包、readiness 门禁、答辩脚本、中文操作手册。
