# docs 目录文档导航

本目录用于集中保存 FinDSL Forge 的中文项目文档、专项技术说明、比赛提交说明和长期维护资料。根目录的 `README.md` 适合快速了解项目与启动命令，`PROJECT_INDEX.md` 适合查找文件和判断目录作用；本文件则用于帮助读者在 `docs/` 中选择应该阅读的文档。

## 编号中文文档体系

| 文档 | 主要用途 |
| --- | --- |
| `01_项目简介.md` | 说明项目背景、赛题定位、核心能力、读者对象和交付价值。 |
| `02_用户手册.md` | 面向普通使用者，说明 DSL 编译、自然语言建议、SQL 验证和 Web Demo 使用方式。 |
| `03_操作手册.md` | 面向演示和运维人员，说明本地启动、脚本执行、证据采集和异常排查。 |
| `04_开发者文档.md` | 面向开发者，说明开发环境、主要流程、扩展方式和代码提交注意事项。 |
| `05_项目架构说明.md` | 说明编译器、语义校验、SQL 生成、验证链路、Demo 服务和 Doris 证据链的总体架构。 |
| `06_代码结构说明.md` | 说明源码、配置、数据、脚本、测试、报告和交付物目录的职责边界。 |
| `07_核心模块说明.md` | 说明词法解析、语法解析、AST、语义校验、SQL 编译、参考验证和自然语言辅助模块。 |
| `08_算法说明.md` | 说明 DSL 解析、类型约束、窗口语义、排序截断、前缀和优化和 SQL/reference 等价验证思路。 |
| `09_接口文档.md` | 说明 CLI 命令、Web API、脚本入口和主要输入输出约定。 |
| `10_数据说明.md` | 说明示例数据、真实样例、生成数据、Doris 数据资产和报告证据的使用边界。 |
| `11_配置说明.md` | 说明指标、表映射、LLM Provider、部署脚本和项目元数据配置。 |
| `12_环境依赖与部署.md` | 说明 Python、PowerShell、Docker/Doris、MySQL 客户端和可选依赖的部署方式。 |
| `13_测试说明.md` | 说明单元测试、集成验证、官方样例套件、就绪检查和测试证据读取方式。 |
| `14_常见问题FAQ.md` | 汇总环境、命令、DSL、Doris、LLM、报告和提交过程中的常见问题。 |
| `15_更新日志.md` | 记录文档体系建立及项目能力演进摘要，并引用根目录 `CHANGELOG.md`。 |
| `16_历史文件说明.md` | 说明历史文件、临时文件、生成报告和可归档内容，强调不直接删除。 |
| `17_项目交付说明.md` | 说明比赛提交包、答辩材料、验收顺序、风险项和人工复核事项。 |
| `18_企业级审计与补强报告.md` | 记录功能、代码、算法、安全边界和交付成熟度审计，以及本轮补强内容。 |
| `20_官方真实数据适配分析与开发计划.md` | 说明官方真实 CSV、官方槽位 DSL、覆盖率结果、已完成语义修复和当前缺口。 |
| `21_官方真实数据冲刺计划与验收闭环.md` | 说明拿到官方真实数据后的冲刺路线、Doris 验收闭环、风险口径和后续执行顺序。 |
| `22_官方真实数据落库复盘与满分冲刺计划.md` | 说明官方 CSV 全量落库、Doris 特征表构建、证据结果、根因修复和下一步满分冲刺计划。 |

## 阅读建议

首次接触项目时，建议按 `README.md`、`PROJECT_INDEX.md`、`docs/01_项目简介.md`、`docs/03_操作手册.md` 的顺序阅读。准备比赛答辩时，建议重点阅读 `docs/17_项目交付说明.md`、`docs/18_企业级审计与补强报告.md`、`docs/20_官方真实数据适配分析与开发计划.md`、`docs/21_官方真实数据冲刺计划与验收闭环.md`、`docs/22_官方真实数据落库复盘与满分冲刺计划.md`、`docs/requirement_mapping.md`、`docs/defense_walkthrough.md` 和 `submission_artifacts/evidence_snapshots/` 下的证据文件。继续开发时，建议先阅读 `docs/04_开发者文档.md`、`docs/05_项目架构说明.md`、`docs/07_核心模块说明.md` 和 `docs/13_测试说明.md`，再修改源码或配置。
