# 10 数据说明

本文档说明项目中的样本数据、真实样本、生成数据和数据使用口径。

## 1. 数据目录

```text
data/
├── samples/
├── real_samples/
└── generated/       # 已被 .gitignore 忽略
```

## 2. `data/samples/`

该目录是项目测试和 Demo 默认数据。主要文件：

- `daily_quote.csv`：日行情表，含 `ts_code`、`trade_date`、`close`、`turnover_rate`、`volume`。
- `money_flow.csv`：资金流表，含 `main_net_inflow`，用于多表 join 和稀疏辅助表测试。
- `stock_universe.csv`：股票市场归属表，含 `market`。
- `queries.jsonl`：评估用 DSL 案例。
- `official_positive_cases.jsonl`：官方风格正例。
- `official_negative_cases.jsonl`：官方风格负例。
- `llm_candidate_response.json`：模拟 LLM 响应。

## 3. `data/real_samples/`

当前真实样本位于 `eastmoney_a_share_sample/`。它使用东方财富公开历史 K 线接口缓存，覆盖贵州茅台和平安银行的一段日线数据。该样本用于展示真实股票代码、日期和行情字段，不作为 Doris 5M 行性能证明。

其中 `money_flow.csv` 是中性占位数据，用于兼容三表加载器；文档和答辩中不得把它描述为真实资金流数据。

## 4. `data/generated/`

该目录保存合成规模数据，例如 Doris 1M、5M 或 scale benchmark 数据。它可以由脚本重新生成，已被 `.gitignore` 忽略，不建议提交到 Git。

## 5. 数据语义注意事项

1. `daily_quote` 是股票-交易日骨架。稀疏辅助表应 left join 到该骨架，避免丢失没有资金流记录但有行情记录的行。
2. `NULL` 参与比较时应按 SQL 三值逻辑处理。
3. prefix 表构建要保持 row_no 与交易日骨架对齐，否则 rolling sum 会发生日期错位。
4. 真实行情样本和合成性能数据承担不同角色，不能混用性能结论。
