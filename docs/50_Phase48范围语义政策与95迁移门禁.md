# Phase 48 范围语义政策与 95% 迁移门禁

## 1. 本阶段解决了什么

Phase 47 结束时，ANTLR/Typed AST/Logical IR/Physical IR 新链路已经迁移旧严格成功集中的 `1022/1097` 条，剩余 75 条都停在 `PHYSICAL_SCOPE_DATA_UNAVAILABLE`。这批问句不是同一种问题：有些名称可以由交易所规则或公开分类可靠解释，有些是录入噪声，有些属于事件集合，还有一些根本超出当前 A 股日频数据域。若把它们全部塞进普通别名表，数字会变好看，但系统无法说明为什么这样映射，也无法在业务口径变化时安全替换。

本阶段新增独立的范围语义政策层。它不改变 ANTLR 文法，也不在规划器中增加某个比赛词项的硬编码分支。每项政策都要声明解析方式、源快照、成员数上下限、公开依据、置信度、风险等级、审核状态、生效日期和适用边界。构建器只接受三种可复核的解析方式：复制一个完整公开范围、按证券名称规则从完整身份快照筛选、对多个完整范围做集合交并。运行时若发现政策目标没有出现在最新目录中，会直接报错，不会偷偷选择同名的另一来源。

实施后，旧严格成功集迁移达到 `1044/1097（95.17%）`，5,799 条官方工作簿中的新后端总成功数达到 1,076。与 Phase 47 相比，严格迁移增加 22 条，总成功增加 23 条；新增的另一条来自旧后端未支持但新架构能够正确处理的问句。剩余 53 条严格缺口仍全部保留为范围数据不可用，没有用空结果、单证券伪板块或编辑距离猜测制造成功。

## 2. 声明式政策模型

政策配置位于 `configs/official/scope_semantic_policies.json`，结构约束位于同目录的 `scope_semantic_policies.schema.json`。运行时由 `ScopeSemanticPolicyCatalog`执行比 JSON Schema 更严格的语义校验，包括别名规范化冲突、政策 ID 重复、风险等级是否被当前 profile 允许、审核状态、日期格式、成员数上下限，以及不同解析方式所需字段是否完整。

三种解析方式各自承担清楚的责任：

1. `exact_scope` 复制指定来源快照中的完整范围，并保留源代码和源快照；
2. `security_name_regex` 从指定证券身份快照按受控名称规则生成成员，不接受任意字段或任意脚本；
3. `set_operation` 对两个以上完整来源按 `(mktcode,tgtcode)` 稳定键求交或求并，同时校验每个分量和最终结果的成员数。

构建结果写入新的 `curated-scope-alias` 快照。当前快照为 `curated-scope-alias-2026-08-01-fe823e5c4d5a`，共物化 13,027 条审核范围成员；外部 Doris 目录加载后包含 220,295 条范围成员、40,907 条行业成员和 5,686 条交易规则，三张表的 Stream Load 均为零过滤行。

## 3. 首批七项政策

| 政策 | 解析方式 | 源成员 | 风险 | 解释边界 |
|---|---|---:|---|---|
| `S板/s板/s版` | 证券简称规则 | 1 | 低 | 深交所规定未完成股权分置改革的 A 股简称前冠 S；当前快照命中 S佳通，不反推历史状态 |
| `深海经济` | 精确公开范围 | 140 | 中 | 比赛 profile 按深海科技主题解释，不等同于完整海洋经济产业 |
| `科技/科技板块/科技类` | 精确公开范围 | 1,220 | 中 | 未限定细分行业时采用宽口径 TMT，这是可替换业务政策，不是普遍行业等式 |
| `中心概念板块` | 白名单录入修正 | 613 | 中 | 仅把该完整词项解释为数据中心，不向其他“中心”词泛化 |
| `海商激光测距` | 白名单录入修正 | 89 | 中 | 按激光雷达主题解释，不启用关键词自动映射 |
| `谷子cop` | 白名单录入修正 | 121 | 中 | 按文创玩具（谷子经济）解释，不启用通用拼写相似度 |
| `上海水利工程` | 上海∩水利建设 | 11 | 低 | 444 只上海地域成员与 267 只水利建设成员求交，仅代表当前公开截面 |

`S板`的规则依据来自深交所《关于上市公司股权分置改革实施有关交易事项的通知》。通知明确规定，尚未进行股权分置改革或方案尚未实施的公司，其 A 股股票简称前冠 S，并自 2006 年 10 月 9 日起实施。项目使用 `^S(?!T)` 规则生成当前成员，独立参考 SQL 则以 `LIKE 'S%' AND NOT LIKE 'ST%'`重建同一集合，避免把 ST 股票误纳入。

`深海经济`和宽口径`科技`被明确标为比赛 profile 的业务政策。2025 年政府工作报告将深海科技列为需要安全健康发展的新兴产业，这能支持深海科技具有独立产业主题，却不能证明“深海经济”在所有机构中都只有一个定义。因此配置保留中风险标记和数据边界。赛题方若给出自己的分类，只需替换政策目标和快照，不需要修改 ANTLR、Typed AST、Logical IR、Physical IR 或 SQL 后端。

## 4. 编译链路中的审计位置

政策不是只存在于构建报告中。`ExternalScopeRuntimeCatalog`解析政策别名时，会先要求运行时范围代码与政策计算出的目标一致。目标缺失或漂移会抛出 `ExternalScopeRuntimeError`。进入物理规划后，`PhysicalExternalExists`除了范围代码和快照 ID，还保存 `policy_id`、`semantic_basis`、`risk_level`和依据链接。这样 AST/IR 展示可以回答“为什么采用这个范围”，而 SQL 仍只携带执行所需的受控过滤条件。

这种分工避免了两个常见问题。第一，政策说明不会变成 SQL 注释或动态字符串，数据库执行面保持简洁；第二，审计信息不会在降到 SQL 时完全丢失，答辩或线上排查可以从 Physical IR 追溯到配置。新增范围政策只改 JSON 并重建目录，核心编译器代码改动为 0 行，直接对应赛题“业务逻辑与编译内核解耦”和配置扩展要求。

## 5. 官方工作簿与 Doris 结果

Phase 48 漏斗完整处理官方 5,799 条工作簿，没有只跑新增样例。结果如下：

| 指标 | Phase 47 | Phase 48 | 变化 |
|---|---:|---:|---:|
| 旧严格成功集 | 1,097 | 1,097 | 0 |
| 已迁移旧严格成功 | 1,022 | 1,044 | +22 |
| 严格迁移率 | 93.16% | 95.17% | +2.01 个百分点 |
| 新后端总成功 | 1,053 | 1,076 | +23 |
| 严格迁移缺口 | 75 | 53 | -22 |

这里的 `95.17%` 是“旧严格成功集迁移率”，不是对未知隐藏测试集的整体 SQL 正确率。赛题要求的“编译生成 SQL 正确率不低于 95%”最终仍应由赛题方给定输入和期望结果验收。项目保留这一区分，是为了避免把覆盖率当准确率。当前能证明的是：旧架构已经确认可处理的 1,097 条中，新架构迁移 1,044 条；本阶段七项政策又通过了独立完整行集验证。

差量审计自动提取相对 Phase 47 新增的 23 条成功问句，每条在真实 Doris 上执行 5 次。结果为 `23/23 PASS`，结果行数与哈希跨轮稳定，12 条返回非空结果，最高 P95 为 7,781.178 ms，低于赛题 10 秒门禁。该最慢值来自包含连续状态计算的深海经济阳线场景；简单政策查询的最高 P95 只有 234.4579 ms。

## 6. 独立参考 SQL 证明了什么

仅执行生成 SQL 不能排除“SQL 能跑但范围选错”的问题，因此 `collect_phase48_scope_policy_evidence.py`没有复用生成 SQL，而是从原始来源重建七套成员集合。精确范围直接读取源快照和源范围代码；S 板按证券简称条件重建；上海水利工程直接对上海和水利建设源集合执行 `INTERSECT`。随后脚本完成两层比较：

1. 原始来源成员集合与物化政策成员集合比较全部 `7/7` 一致；
2. 独立参考 SQL 与编译器生成 SQL 的完整 `(mktcode,tgtcode,bizdate)` 行集比较全部 `7/7` 一致。

比较使用排序后的完整行集 SHA-256，不以“行数恰好相同”代替语义一致。七项政策的 Physical IR 溯源字段与 SQL 快照绑定也全部通过。每项 DSL 重复编译 20 次，七项 P95 均低于 50 ms，最大值为 16.4243 ms；每项简单查询执行 5 次，七项 P95 均低于 10 秒。

## 7. 剩余 53 条为什么没有强行补齐

最终严格缺口对应 57 个尚未解析原子、76 次出现。它们大致分为四类：

- 事件或相对日期集合，如大订单、连板概念、龙回头，不能用当前静态板块冒充历史事件成员；
- 没有唯一行业含义的词，如英美贸易业、音频媒体行业、石膏石材板块和运动用品；
- 疑似噪声或虚构名称，如 100429、994338、深证龙科、香港金科、杨氏纸业；
- 超出当前 A 股日频数据域的证券或产品，如腾讯控股、指数基金、白酒 ETF，以及需要其他资产类别或历史成员数据的问句。

公开目录中虽然能找到相近主题，例如“昨日连板”“英伟达概念”或“体育产业”，但相近不等于等价。将 `连扳概念`绑定当前“昨日连板”会产生时间穿越，将 `BLacKweLL`直接扩成全部英伟达概念会扩大范围，将`运动用品`随意映射体育产业或运动服装会改变行业边界。系统继续返回 `PHYSICAL_SCOPE_DATA_UNAVAILABLE`，这比生成看似完整但不可证明的 SQL 更符合金融系统的审计要求。

## 8. 与赛题量化指标的关系

本阶段直接加强三个评分点。声明式政策使新增业务范围不修改核心编译器；20 次重复编译的最大 P95 为 16.4243 ms，低于 50 ms；23 条新增真实问句执行均低于 10 秒。迁移率超过 95%进一步表明新架构已经覆盖旧后端绝大多数可落地能力，但不替代正式正确率验收。

19 年查询十倍加速由既有 Phase 6C 和长周期 Doris 证据承担，本阶段没有重新包装该指标。项目现有性能证据、配置零侵入证明、ANTLR 文法、强类型 IR 和 Phase 48 范围政策共同构成完整评分链；任何单项数字都不应独立解释为“赛题满分”。
