# 07 核心模块说明

本文按“作用、输入、输出、依赖关系和维护边界”说明当前正式模块。旧内部 FinDSL 模块不再称为项目主干，详见末节。

## 1. 正式编译编排

涉及文件：`src/findsl/official/pipeline.py`。

输入是官方七槽位 DSL、解析模式、目录与策略快照，输出是 frontend、Typed AST、Logical IR、优化轨迹、Physical IR、Doris SQL 或结构化失败。它负责阶段编排和 partial evidence，不实现具体语法、语义或 SQL 规则。CLI、Demo 和证据脚本最终都应调用这一应用服务。

## 2. ANTLR 前端

涉及文件：`grammar/OfficialSlot.g4`、`src/findsl/official/frontend/`。

输入是原始 DSL 文本，输出是项目 AST、源位置、标准化文本、修复记录和诊断。ANTLR generated 文件由 `scripts/generate_antlr.py` 生成并由 CI 校验，不手工修改。严格模式不得静默修复；恢复模式只允许可审计白名单。

## 3. 强类型语义模块

涉及文件：`typed_ast.py`、`semantics.py`、`signatures.py`、`policy.py`、`registry.py`。

输入是无类型 AST 和版本化目录，输出是不可变 Typed AST 或稳定错误码。它检查函数签名、槽位、参数、数值/布尔/时间类型和业务政策引用。语义层不能选择物理表，也不能反向调用 `official_slot.py`。

## 4. 领域绑定模块

涉及目录：`src/findsl/official/domain/`。

输入是 Typed AST、指标/范围目录和语义政策，输出是金融领域表达、市场集合、时间语义和数据需求。该层负责说明“查询想表达什么”，并在缺少数据或政策未定义时 fail closed。它与外部目录通过明确接口协作，不在运行时抓取任意网络数据。

## 5. 关系 IR 模块

涉及目录：`src/findsl/official/ir/` 和 `lowering.py`。

输入是已绑定领域模型，输出是 SQL 无关的关系计划。核心节点包括 Scan、Filter、Project、Join、Aggregate、Window、Rank、Stage 和 Set Operation。IR validator 检查节点类型、字段作用域和计划合法性。该层不应出现 Doris 表名或 SQL 片段。

## 6. 等价规则模块

涉及目录：`src/findsl/official/optimizer/`。

输入是 Logical IR，输出是等价计划和规则 trace。规则包含稳定 ID、匹配条件、变换和证明义务；它们只负责语义等价，不把延迟或扫描成本写入重写条件。当前引擎仍以固定 pass 为主，后续接入轻量 memo 去重和候选枚举。

## 7. 物理规划模块

涉及目录：`src/findsl/official/physical/`。

输入是 Logical IR、Physical Catalog、Statistics Snapshot 和策略配置，输出是候选 Physical IR、成本分量、风险和选择理由。模块覆盖资源绑定、范围、日期、事件、排名、prefix、固定特征和多资源 Join。`planner.py` 当前较大，后续按范围绑定、表达式规划、时序规划、候选枚举和选择拆分。

## 8. Doris 后端

涉及目录：`src/findsl/official/backend/`。

输入是通过验证的 Physical IR，输出是 SQLGlot Doris AST、只读 SQL、校验结果和可选执行差分。后端负责 Physical IR 到方言节点的确定性映射，validator 负责单 SELECT/WITH、表列白名单、无 DDL/DML、稳定顺序和窗口合法性。配置中的任意 SQL 文本不能直接进入 renderer。

## 9. 外部数据目录

涉及目录：`src/findsl/official/external/`。

输入是受控 Provider 配置、公开/第三方源和快照日期，输出是带来源、有效期、成员数和审核状态的数据目录。它解决行业、指数、板块和证券身份等物理范围问题，不负责猜测业务别名。完整性不足的数据只能进入实验 profile 或产生结构化不可用诊断。

## 10. 正确性与证据

涉及文件：`reference.py`、`equivalence.py`、`official_*_evidence.py`、`official_gap_analysis.py`、`evidence_metadata.py`、`readiness.py`。

输入是 DSL、测试数据、Doris 查询结果和证据快照，输出是完整结果差异、覆盖漏斗、能力分类、性能统计和提交门禁。独立 oracle 不复用被测 planner 或 renderer。`official_gap_analysis.py` 把 5799 条按能力族分类，防止逐行修补。

## 11. AI 辅助与展示

`nl2dsl.py`、`llm_adapter.py` 和 `llm_provider.py` 输入中文需求或模型响应，输出受控 DSL 候选；候选仍进入正式编译和验证。`demo.py` 输入 HTTP 请求，输出编译过程、SQL、IR、验证、性能和诊断界面。模型不能获得 Doris 写权限，Demo 不能复制核心规则。

## 12. 兼容模块

`src/findsl/compat/official_frontend/` 保存手写前端适配和 ANTLR/手写差分；`official_slot.py`、`compiler.py`、`lexer.py`、`parser.py`、`semantic.py`、`sqlgen.py`、`ast_nodes.py` 属于早期手写管道。它们仍服务内部 FinDSL 样例和历史回归，因此暂时保留；新增官方函数、语义和物理策略不得写入这些模块。兼容层可以调用正式核心，正式核心到兼容层的反向依赖由 CI 禁止。
