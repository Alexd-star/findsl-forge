您好！我们正在参加第五届中国研究生金融科技创新大赛赛题 19“行情选股 DSL 到高性能 Doris SQL 的自动化编译系统”。目前已经完成官方槽位 DSL 的 ANTLR 解析、强类型 AST、逻辑计划、物理计划和 Doris SQL 后端，并将官方提供的三张 CSV 导入 Doris 进行了逐条编译与执行验证。

在继续完善全量覆盖时，我们发现部分 DSL 的执行需要“范围成员关系、行业分类、标的交易属性”或规范中尚未明确的排序语义。为了避免自行猜测业务口径、生成无法与赛题标准结果对齐的 SQL，想请赛题组帮助确认下列问题。我们并非要求赛题组必须补充所有数据；若允许参赛队依据公开规则或外部数据自行构建，也烦请明确允许范围、推荐口径及最终评测时的对齐方式。

当前收到的资料包括 `选股提槽实例.xlsx`、`hsj_stock_code_info.csv`、`hsj_stock_hq_basic.csv` 和 `hsj_stock_hq_ext.csv`。代码表共 5,686 行，其中 `hyBlkRefName` 全部为空，`majorType`、`kcbFlag`、`gemFlag`、`bShareFlag` 等字段当前均为单一值 0；行情表主要是日频数据。基于这些资料，我们可以可靠完成行情、资金流和由 OHLCV 确定性派生的技术指标，但无法唯一恢复概念、行业、指数和自定义板块的历史成员关系，也无法从日频行情唯一判断所有标的的 T+0 交易资格。

烦请重点确认以下七项：

1. `filter_scope` 中行业、概念、指数、板块等范围，是否会另行提供“范围—证券”成员关系表？如不提供，是否允许参赛队使用公开或第三方数据自行构建？最终正确率评测使用哪一版本、哪一日期的成员快照？
2. `belong_industry` 使用哪套行业分类标准和层级，例如申万 2021、中证、证监会或华泰内部分类？是使用查询日期当时的历史行业归属，还是使用当前最新归属？
3. 规范要求“没有特定排名指标时，将 `rank.indicator_name` 置空”。此时排名依据究竟是什么：范围权重、相关度、热度、股票代码稳定序、其他默认指标，还是仅表示截取任意 N 个成员？若没有业务排序依据，是否应将这类表达视为不可执行语义？
4. `是否T+0` 的适用标的范围和判断规则是什么？如果当前数据集仅包含 A 股股票，是否可以将其统一解释为 False；如果包含 ETF、债券、可转债等标的，是否会提供标的类型及生效日期维度的 T+0 属性？
5. 对 `X日均线`、`X日均量线`、上穿/下穿/金叉等任意周期技术指标，是否统一使用股票前复权价格计算？前复权公式是否为“原始价格 × `qfqMulti` + `qfqAdd`”？停牌日是否跳过，并按每只证券最近 N 条有效交易记录计算？
6. 当普通 `indicator` 与 `queryData` 使用不同 `filter_scope/keywords` 时，是否应先分别计算两个独立关系，再做标量或按证券比较？例如工作簿第 1415 行中，`IPV6概念` 与 `白酒|ai|建筑` 的比较应采用何种集合、聚合和时间桶语义？
7. 赛题说明中提到“覆盖 20 年的模拟 A 股历史行情数据集”以及物化视图、前缀和表元数据。当前收到的基础行情日期范围约为 2015 年至 2026 年，衍生行情约从 2019 年开始。后续是否还会提供另一套正式评测数据、结果真值、物化视图或前缀表？`选股提槽实例.xlsx` 是语法训练语料，还是要求全部对当前三张表生成可执行 SQL 的评测全集？

为便于赛题组快速定位，我们已附上 355 条当前严格迁移缺口的逐行明细。该数字是我们内部“旧严格成功集 1,097 条迁移到新 Typed IR/SQLGlot 后端”的剩余量，不代表官方 5,799 条语料中只有 355 条存在数据问题，也不作为赛题完成率口径。明细按首个终止错误分类，同一行在解决首个问题后还可能暴露第二个依赖，例如 35 条空指标排名中有 19 个排名调用同时使用了非空 `filter_scope`。

## 四、需要赛题方补充或确认的最小数据合同

如果赛题方愿意补充数据，建议只需提供下列最小字段，不必提供新的宽表。

### 4.1 范围成员关系

| 字段 | 含义 |
|---|---|
| `scope_type` | 行业、概念、指数、板块、地域或其他范围类型 |
| `scope_code` | 稳定范围编码 |
| `scope_name` | 工作簿中使用的标准名称 |
| `scope_alias` | 可选别名，用于大小写、简称和同义词归一 |
| `mktcode`、`tgtcode` | 与官方证券主键一致的成员证券 |
| `effective_from`、`effective_to` | 成员关系生效区间；若只提供当前快照请明确说明 |
| `weight` | 指数权重或范围内默认排序权重；没有则允许为空 |
| `source_version` | 数据版本、快照日期或发布批次 |

### 4.2 行业归属

| 字段 | 含义 |
|---|---|
| `classification_system` | 行业分类体系及版本，例如申万 2021 |
| `industry_level` | 一级、二级或三级 |
| `industry_code`、`industry_name` | 行业编码和名称 |
| `mktcode`、`tgtcode` | 所属证券 |
| `effective_from`、`effective_to` | 历史归属生效区间 |

### 4.3 标的交易属性

| 字段 | 含义 |
|---|---|
| `instrument_type` | 股票、ETF、LOF、债券、可转债等 |
| `t0_eligible` | 是否允许当日回转交易 |
| `effective_from`、`effective_to` | 规则生效区间 |
| `rule_source` | 交易规则或赛题口径版本 |

## 五、代表性原始 DSL，便于赛题方快速判断

### 5.1 范围成员关系

- Excel 第 29 行：`indicator('京|沪', '鸡肉概念|家电类', '振幅', '05年', '', '', '') > 5% ...`
- Excel 第 71 行：`rank('沪|深|京', '算力', '总股本', 'asc', '', '', '', '') <= 10`
- Excel 第 120 行：`indicator('创业板', '储能&数据中心', '最新价', '', '', '', '') < 30`
- 高频范围包括 `aigc`、`白酒行业`、`SHEIN`、`算力`、`S板`、`深海经济`、`ai`、`低空经济`、`华为`、`上证周期` 等。

### 5.2 空指标排名

- Excel 第 386 行：`rank('', '大订单概念', '', 'desc', '', '', '', '') <= 10`
- Excel 第 697 行：`rank('', '', '', 'desc', '', '', '', '') = 1`
- Excel 第 791 行：同一表达式中出现两个空指标 rank，并分别限制百分比和名次数量。
- Excel 第 4688 行：先比较连涨/连跌天数，再按空指标在“今年以来”排名前五。

### 5.3 行业聚合

- Excel 第 1141 行：个股涨幅高于所属行业平均涨幅，再按成交额取第一名。
- Excel 第 1182 行：个股市盈率高于行业最高市盈率，并叠加上周成交量排名。
- Excel 第 3029 行：总市值进入前 20%，且高于所属行业平均总市值的 120%。

### 5.4 T+0

- Excel 第 4344 行：非科创板、`是否T+0=True`、连续 5 日上涨，再 `limit 0,1`。
- Excel 第 4369 行：全市场筛选 `是否T+0=True`。

### 5.5 跨范围时序比较

- Excel 第 1415 行：`indicator('', 'IPV6概念', '收盘价', '近两年', '', '', 'EXIST=9季度') <= queryData('', '白酒|ai|建筑', '收盘价', '近两年', 'AVG')`

## 六、不建议向赛题方索要、项目可自行完成的内容

27 条 `DOMAIN_DATA_UNAVAILABLE` 主要涉及 `3/7/11/13/15/17/20/24/25/27/30/45/47/50/55/60/120/144/200/233/240/754/850 日均线`、任意周期均量线及其上穿、下穿、金叉、回调和增长率。这些特征可以基于 `lastPx/closePx`、`volume`、`qfqMulti`、`qfqAdd` 和交易日期确定性生成。项目应使用参数化 Window IR、Prefix IR 或物化特征表完成，而不应把它们继续归为必须由赛题方补数据。

需要向赛题方确认的只是计算口径：股票是否统一前复权、复权公式、停牌日是否跳过、N 日是否指最近 N 个有效交易观测，以及查询起始日前是否允许读取窗口预热数据。
