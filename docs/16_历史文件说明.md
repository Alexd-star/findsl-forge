# 16 历史文件说明

本文档记录项目中可能属于历史、临时、重复或可归档的文件。当前未删除任何文件，也未移动现有文件。

## 1. 历史文件判断原则

一个文件可被视为历史或可归档，通常满足以下条件之一：

- 已有更新版本替代；
- 属于一次性实验或阈值探测；
- 属于本地渲染 QA、浏览器缓存、临时日志；
- 可由脚本重新生成；
- 不参与当前运行、测试、部署、提交包主线。

1. 在本文件中添加归档记录。
