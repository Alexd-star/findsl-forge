# 12 环境依赖与部署

本文档说明本地开发、Web Demo、Doris 环境和提交证据所需依赖。

## 1. Python 环境

要求 Python 3.9 及以上。项目核心包无强制第三方运行依赖；测试和 reference oracle 需要：

- `pytest>=8.0`
- `pandas>=2.0`

项目配置见 `pyproject.toml`。

## 2. 本地运行

```powershell
$env:PYTHONPATH="src"
python -m pytest -q
python -m findsl.cli compile 'filter(indicator("close") > 10)'
```

## 3. Web Demo 部署

本地启动：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\serve_demo.ps1
```

默认监听 `127.0.0.1:8765`。该 Demo 适合本机演示，不建议直接暴露到公网。

## 4. Doris 环境

需要：

- Docker Desktop for Windows；
- WSL2 + Ubuntu（推荐）；
- Apache Doris Docker compose 环境；
- MySQL-compatible client，用于连接 Doris 9030 端口。

快速启动见 `deploy/doris/README.md` 和 `docs/doris_runbook.md`。

## 5. 代理设置

如果 Docker 拉取镜像需要代理，可使用本机代理：

```powershell
$env:HTTP_PROXY="http://127.0.0.1:7897"
$env:HTTPS_PROXY="http://127.0.0.1:7897"
```

项目脚本 `prepare_doris_scale_evidence.ps1` 支持 `-ProxyUrl` 参数。

## 6. 部署注意事项

1. 本地 Docker Doris 适合比赛证据和演示，不等于多节点生产集群。
2. 生产环境应重新评估 bucket 数、replication、冷热分层、权限和备份。
3. 修改 Doris schema 后必须重新构建 prefix 表，并重新采集 evidence。
4. 证据采样时应禁用 SQL cache，避免重复查询缓存影响性能结论。
