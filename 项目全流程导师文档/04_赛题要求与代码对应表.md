## 需要待核验的地方

1. 官方赛题原文逐字版本：当前项目没有把官方题面 PDF 放入本表。核验方法是找到原赛题文件，逐条和 `docs/requirement_mapping.md` 对照。
2. 现场 Doris 环境：当前有 5M evidence 快照，但如果评委要求现场重跑，需要确认 Docker Desktop、Doris、MySQL client、端口 9030 都可用。
3. 真实 LLM provider：项目支持 provider，但最终提交不依赖真实 provider。若现场演示真实模型，需要提前配置 API Key 和超时参数。
