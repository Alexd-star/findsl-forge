## 发送前注意

1. `355` 是项目内部旧严格成功集 1,097 条迁移到新后端后的剩余量，不是官方 5,799 条语料的失败总数。
2. 27 条任意周期均线/均量及穿越类技术特征可由官方 OHLCV 和复权因子自行派生，不要求赛题方补新数据，只询问计算口径。
3. 275 条范围成员关系、15 条行业聚合、35 条空指标排名、2 条 T+0 和 1 条跨范围时序比较需要赛题方提供数据或明确语义。
4. 各类别按“首个终止错误”统计。同一 DSL 解决当前错误后可能仍需要另一项数据，例如空指标排名中有 19 个调用同时使用非空范围。
5. 邮件正文中的联系人称呼可在发送前按实际沟通渠道调整；不要删掉评测范围、外部数据许可和快照日期三项核心问题。
