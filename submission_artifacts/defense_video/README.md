# 一分钟答辩视频资产

本目录用于保存由 `scripts/build_defense_video.py` 生成的视频文件。视频素材来自已版本化的 Web Demo 截图，默认输出：

`findsl_forge_one_minute_demo.mp4`

生成脚本会重新合成画面和字幕，因此如果 Web Demo 截图更新，只需要重新运行：

```powershell
python scripts\build_defense_video.py
```

正式提交前建议人工观看一遍 MP4，并按 `submission_artifacts/defense_video_script.md` 补录或现场讲解旁白。
